# Release Checklist

- Replace privacy policy URL.
- Replace terms of use URL.
- Confirm final Bundle ID.
- Confirm app version.
- Confirm build number strategy.
- Configure iOS signing.
- Configure Android release signing before Play Store builds.
- Replace Flutter template app icon with final branded icon.
- Prepare App Store screenshots.
- Prepare App Store description.
- Complete Apple privacy questionnaire.
- Confirm Open Food Facts attribution.
- Run `flutter analyze`.
- Run `flutter test`.
- Build Android APK.
- Build Android AAB.
- Build iOS IPA on Codemagic or Mac.
- Install on Android real device.
- Install on iPhone real device/TestFlight.
- Remove or replace placeholder legal links.
- Check no secrets are committed.
- Review Premium placeholder.
- Review camera permission copy.
- Archive succeeds.
- TestFlight upload succeeds.
