# CODEMAGIC COCOAPODS FIX REPORT

## 1. Root cause

The Codemagic error reported for the previous build was:

```text
Unable to find a specification for webview_flutter_wkwebview depended upon by google_mobile_ads
```

In the current repository state, `google_mobile_ads` is not present in `pubspec.yaml`, `pubspec.lock`, `.flutter-plugins-dependencies`, or the Dart/iOS source files. Therefore `webview_flutter_wkwebview` is also not expected in the current resolved dependency graph.

The current iOS project still had configuration problems that could affect CocoaPods resolution and Codemagic reproducibility:

- `ios/Podfile` used `platform :ios, '13.0'` instead of the required iOS 15.0.
- `ios/Podfile` included unnecessary `use_frameworks!` and `use_modular_headers!`.
- Codemagic installed Pods without a preflight check proving that Flutter plugin metadata had been generated by `flutter pub get`.
- Codemagic skipped CocoaPods entirely if `ios/Podfile` was missing, which could hide a broken iOS project instead of failing early.

## 2. Podfile missing or incomplete

`ios/Podfile` exists.

It was not missing, but it was not aligned with the required final configuration because the deployment target was 13.0 and the Runner target had unnecessary framework/header directives.

## 3. Final Podfile content

```ruby
platform :ios, '15.0'

ENV['COCOAPODS_DISABLE_STATS'] = 'true'

project 'Runner', {
  'Debug' => :debug,
  'Profile' => :release,
  'Release' => :release,
}

def flutter_root
  generated_xcode_build_settings_path = File.expand_path(File.join('..', 'Flutter', 'Generated.xcconfig'), __FILE__)
  unless File.exist?(generated_xcode_build_settings_path)
    raise "#{generated_xcode_build_settings_path} must exist. Run flutter pub get first."
  end

  File.foreach(generated_xcode_build_settings_path) do |line|
    matches = line.match(/FLUTTER_ROOT\=(.*)/)
    return matches[1].strip if matches
  end
  raise 'FLUTTER_ROOT not found in Generated.xcconfig.'
end

require File.expand_path(File.join('packages', 'flutter_tools', 'bin', 'podhelper'), flutter_root)

flutter_ios_podfile_setup

target 'Runner' do
  flutter_install_all_ios_pods File.dirname(File.realpath(__FILE__))
end

post_install do |installer|
  installer.pods_project.targets.each do |target|
    flutter_additional_ios_build_settings(target)
  end
end
```
